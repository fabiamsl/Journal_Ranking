# Originallisten

Hier liegen die heruntergeladenen Originallisten. Sie werden nicht mit ins Repository übernommen.

```
quellen/
├── ABDC-JQL-2025-….xlsx                         ABDC Journal Quality List (Excel)
└── VHB/
    ├── VHB_Rating_2024_Area_rating_BAFI.pdf     ein PDF je VHB-Bereich
    ├── VHB_Rating_2024_Area_rating_BAFI.txt     wird von build_ratings.py erzeugt, falls nicht vorhanden
    └── …
```

Danach im übergeordneten Ordner `python build_ratings.py` ausführen.
